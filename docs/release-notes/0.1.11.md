# Sunrise Tech Check 0.1.11

## What's new

- **One-click updates.** When a newer version is available, the update banner now has an **Install Update** button. Click it and Tech Check downloads the new version, verifies it, swaps itself in place, and relaunches — no more downloading a DMG and dragging it to Applications by hand. If an in-place update isn't possible (for example you don't have permission to write to the install location, or you're running a development build), the banner falls back to the old **Download** button that opens the release in your browser.

## Internal

- New `internal/updater` building blocks: a verified streaming download (checks SHA-256 and byte size against the server-published values, with a 500 MiB hard cap), payload staging adjacent to the install target (same volume, so the swap is a rename), and a detached `--apply-update` helper that waits for the app to quit, swaps the payload into place, and relaunches.
- macOS replaces the `.app` bundle with a two-step rename (move-aside then move-in, rolling back on any caught error). Windows replaces the single `.exe` atomically via `MoveFileEx(MOVEFILE_REPLACE_EXISTING)`. The helper runs from a temporary copy of the binary, so the install location is never locked during the swap.
- On launch the updater sweeps any `.old`/`.new` leftovers next to the install, guarded to do nothing when the install is absent so it can never delete the only surviving copy.
- An update is refused while a Tech Check run is in progress, and concurrent downloads are guarded.
- `golang.org/x/sys` promoted to a direct dependency for the Windows file/process calls (`MoveFileEx`, `OpenProcess`).
