# Sunrise Tech Check 0.1.16

## What's new

- **Shorter runs.** The full set of tests now runs only on the servers nearest to you. The other servers get a quick check.
- **Amazon DCV checks.** Tech Check now also tests the connection that Amazon DCV uses.

## Internal

- Two-phase run: full tests on up to 3 POPs below 100 ms (from the server's run settings). Other POPs get a quick check: latency, DNS and the port checks.
- DCV: TCP 8443 with a TLS interception check, UDP 8443 reachability, and a UDP stream ladder on 8443 (5, 10, 20, 35 Mbps) that reports the highest clean rate.
- Teradici UDP stream on 4172: loss, jitter and large packets.
- Throughput reported per direction. Unmeasured jitter and reorder are omitted, not sent as 0.
