# Sunrise Tech Check 0.1.15

## What's new

- **Clearer updates.** The update banner now shows each step plainly: a progress bar while the update downloads, a green banner with **Restart to update** once it's ready, and a red banner with **Try again** if something goes wrong.

## Internal

- Update banner rewritten around a single phase-driven message (available → downloading → ready → restarting, plus error). Banner and mandatory-update modal buttons drop the global uppercase/tracked button style; the action button keeps a fixed width so label changes don't shift the row.
