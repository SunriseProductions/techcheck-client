# Sunrise Tech Check 0.1.13

## What's new

- **macOS auto-update now works.** Fixed a bug that stopped the in-place update from completing on macOS: clicking **Install Update** quit the app, but the new version was never swapped in and the app didn't reappear. Updating now downloads, swaps, and relaunches as intended. (Windows was unaffected.)

  Because the bug was in the updater itself, this fix can't arrive through the old, broken updater — install 0.1.13 once by hand (download the DMG and drag it to Applications, replacing the old copy). Updates from 0.1.13 onward apply automatically.

## Internal

- The macOS update helper copied only the Mach-O executable out of the `.app` bundle and ran it detached. Under the hardened runtime, a lone executable lifted out of its Developer ID–signed bundle fails signature validation — the signature spans `Info.plist` + `_CodeSignature/CodeResources` — and is SIGKILLed by AMFI the instant it launches. The helper died before it could wait for the app to exit, swap the bundle, or relaunch, leaving the install untouched (and producing no crash report). Windows was unaffected because its artifact is a self-contained `.exe`.
- Fix: copy the entire `.app` bundle with `ditto` (preserving the signature, xattrs, and symlinks) and run the executable from inside the copy. `prepareHelperFromExe` is now platform-split; Windows/Linux keep the single-file copy. Regression test asserts the whole bundle is copied, not just the Mach-O.
